# Agil Gestao Web

Interface web do sistema Agil Gestao para gerenciamento de vendas, desenvolvida com foco em desempenho, organizacao e usabilidade em ambientes reais.

## Sobre o projeto

O Agil Gestao Web e a interface web da solucao Agil Gestao, permitindo o gerenciamento eficiente de vendas, produtos e relatorios de qualquer navegador.

O sistema esta integrado com a aplicacao desktop, sincronizando dados em tempo real para operacoes comerciais.

## Funcionalidades

- PDV (Ponto de Venda) para registro rapido de vendas
- Gestao de produtos e controle de estoque
- Relatorios de vendas detalhados
- Ranking de produtos mais vendidos
- Backup online para seguranca dos dados

## Tecnologias utilizadas

- React
- Vite
- TypeScript
- Tailwind CSS
- Radix UI
- React Router
- Axios
- Sonner (toasts)

## Requisitos

- Node.js 18+
- npm 9+

## Instalacao
